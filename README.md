# 🔥 FitCraft | الاستضافة على Vercel مع الربط المحلي لملفات التمارين

تم ضبط المشروع بحيث يُستضاف **كامل كود الموقع وواجهاته والـ PWA والخطط التدريبية على منصة Vercel**، بينما تبقى **ملفات التمارين الضخمة (407MB - أكثر من 1,323 تمرين متحرك)** مخزنة على جهازك ويتم الربط المباشر بها محلياً.

---

## 🏗️ كيف تعمل هذه المنظومة؟ (Architecture)

```text
┌─────────────────────────────────┐
│     موقعك على Vercel السحابي    │
│   (https://fitcraft.vercel.app) │
│  - واجهة المستخدم والتحكم        │
│  - مولد الخطط الذكي والملتي جيم │
│  - تطبيق الهاتف PWA بدون أشرطة  │
└────────────────┬────────────────┘
                 │
                 │ طلبات الميديا (GIFs / Videos)
                 ▼
┌─────────────────────────────────────────────────────────────┐
│             جهاز الكمبيوتر الخاص بك (Local PC)              │
│       خادم Node.js المحلي (server.js) على المنفذ 8000       │
│                                                             │
│  📁 مجلد التمارين المحلي: gym-exercises (407MB)             │
│                                                             │
│  1. من نفس الكمبيوتر:  http://localhost:8000                │
│  2. من الموبايل (Wi-Fi): http://192.168.1.18:8000          │
│  3. من خارج المنزل:    رابط نفق مشفر (localtunnel)          │
└─────────────────────────────────────────────────────────────┘
```
